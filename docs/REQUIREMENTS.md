# PureFS 需求说明书

## 1. 项目概述

PureFS 是一款完全开源、可自部署的私有云盘系统。可安装在个人小主机、树莓派或普通服务器上，所有数据存储在自有硬件中，完全由用户掌控。

## 2. 核心理念

- **完全开源、可自部署**
- **数据 100% 由用户掌控**：存在自己的硬件上，不上传任何第三方
- **原生文件存储**：文件在服务器上保持普通文件夹结构，不采用任何私有封装格式。即使程序损坏，直接拷贝硬盘即可 100% 带走所有数据
- **零数据扫描、零数据分析**：不触碰、不扫描、不分析用户文件内容
- **自由选择存储介质**：支持本地磁盘、标准对象存储等多种方式

## 3. 功能需求

### 3.1 文件管理

- 默认按**时间降序**排列所有文件
- 三种浏览方式：**列表视图**、**大图标网格视图**、**时间线视图**
- 文件操作：置顶、收藏、批量删除、批量移动、批量重命名
- 权限管理：支持创建多个用户，为不同文件夹分配不同的读写权限

### 3.2 全局搜索

- 搜索文件名
- 搜索文档、图片内的文字内容（全文检索 + OCR，分期实现）
- 精准、快速

### 3.3 分享外链

- 生成分享外链
- 自由设置：有效期、提取码、访问次数限制、下载权限

### 3.4 安全

- **服务端透明加密（AES-256-GCM）**：文件落盘前加密，读取时解密，支持密钥定期轮换
- **双因素认证（2FA）**：TOTP 标准，兼容 Google Authenticator
- **完整操作日志**：记录所有文件操作、登录行为等
- **速率限制**：登录/注册/上传次数限制
- **密码强度校验**：可配置大小写+数字+特殊字符要求

### 3.5 标准协议

原生支持以下协议，电脑、手机、NAS 可直接挂载使用，无需安装专属客户端：

- **WebDAV**
- **SMB**（后续迭代）
- **SFTP**

### 3.6 插件体系

核心系统只保留最基础的文件管理能力，额外功能全部做成可选插件：

- 相册智能整理
- 在线文档编辑
- 离线下载
- 更多……

### 3.7 全平台客户端

| 平台 | 功能 |
|------|------|
| Windows / Mac / Linux 桌面端 | 增量同步、选择性同步、虚拟盘模式 |
| iOS / Android 移动端 | 相册自动备份、文件离线缓存 |

### 3.8 管理员后台

- 系统资源监控（CPU / 内存 / 磁盘）
- 用户管理
- 存储配置
- 一键更新
- 一键备份
- 低配置机器流畅运行

### 3.9 UI 设计

- 简洁高效，**零广告、零弹窗、零冗余推荐**
- 默认**低饱和度浅色**风格
- 支持**深色模式**切换
- 布局清爽直观，常用功能随手可达
- 视觉干净不臃肿

## 4. 非功能需求

- 文件完整性校验：自动定期校验，防止数据静默损坏
- 文件版本管理：保留最近 N 个版本（默认 10），上传覆盖时自动保存旧版本
- 回收站：有回收站，自动清理（默认 30 天）
- 国际化：MVP 内置中/英双语（基础设施已就绪，前端部分完成）
- 部署方式：Docker 镜像 + 裸机二进制均支持
